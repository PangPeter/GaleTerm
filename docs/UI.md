# GaleTerm 桌面 UI 基调与信息架构

> 目标：第一眼像 **Termius Desktop（X）**——数据与终端分离、全宽终端、柔和深色 + 圆角浮层。  
> 实现入口：`apps/gale-desktop`；主题：`themes/gale-termius.json`（`gale-forge.json` 保留作备选）。

---

## 1. 产品气质（基调）

**名称**：**Termius Night** — 消费级精致 SSH 工作台（布局对齐 Termius X，主色偏紫）。

| 维度 | 选择 | 刻意不做 |
|------|------|----------|
| 情绪 | 柔和、抬升、可信赖 | Forge 硬边发丝线 / 霓虹 glow |
| 明暗 | 柔和深灰 canvas；终端内容区略深 | 奶油浅色默认壳 |
| 强调色 | **紫** `#6C5CE7`：主按钮 / 选中 / 导航 | 青绿运维台主色（Forge 备选仍保留） |
| 结构 | 顶栏水平导航 + Vault 页 / 连接 Tab | 常驻左侧 Session Rail |
| 密度 | 中等；主机卡网格；圆角 8–12px | 大留白营销页 / 零圆角刃感 |
| 字体 | UI：系统 UI；终端：**MesloLGS NF** 13px | UI 乱用等宽装饰 |

一句话自检：去掉 Logo 后，第一眼仍应像「现代 SSH 客户端」，而不是运维监控后台。

## 3. 信息架构与层级

```
Application
 └─ Workspace（沉浸式：系统标题栏透明，红绿灯嵌入自绘顶栏）
     ├─ Title Bar      Vault · SFTP | 连接 Tab（可关闭）· +
     └─ Body
         ├─ Vault       左导航（主机/密钥/端口转发/片段/已知主机 … 设置）
         │              + 搜索框 / CONNECT / NEW HOST / TERMINAL + 横向主机卡
         ├─ SFTP        占位
         └─ Terminal    全宽 TerminalPane（单元格默认底色 = 面板底色）
```

无状态栏；提示用右下角浮层 toast。语言切换在 Vault → 设置。

**层级原则**

1. **数据与终端分离**：Vault 管主机；Connections 管已开会话。  
2. **终端尽量全宽**：无常驻侧栏挤占 Stage。  
3. **命令落点**：顶栏高频 + 系统菜单（macOS）+ 快捷键（后续命令面板）。  
4. **状态可扫读**：Status Bar：`状态 · idle · 主题 · 字体 · 语言`。

## 4. 主窗口布局（线框）

```
┌─────────────────────────────────────────────────────────────┐
│ ●●●  [Vault] [SFTP] │ [▣ 本地 ×] [▣ prod ×]  +              │  Title Bar
├────────────┬────────────────────────────────────────────────┤
│ ▣ 主机     │ [🔍 搜索主机或 ssh user@host…      ] [连接]   │
│   密钥     │ [+ 新建主机] [▣ 本地终端]              ⟳      │
│   端口转发 ├────────────────────────────────────────────────┤
│   代码片段 │ 主机 3                                         │
│   已知主机 │ ┌[■] prod ─────┐ ┌[■] bastion ──┐               │
│            │ │    ssh, root │ │    ssh, ops  │               │
│   设置     │ └──────────────┘ └──────────────┘               │
└────────────┴────────────────────────────────────────────────┘
```

SFTP / Settings 本轮仅为导航占位；双栏文件与设置页后续接入同一 Body。

## 5. 菜单规划（第一版）

| 入口 | 内容（规划） |
|------|----------------|
| **Vault** | 主机库、新建主机、刷新 |
| **Connections** | 已开 Tab、新建本地、日后 SSH |
| **SFTP** | 双栏文件（占位） |
| **Settings** | 语言、字体、主题（占位） |
| **系统菜单（macOS）** | 完整命令后续绑定 |

当前迭代：顶栏可视化导航 + 关键命令；完整原生菜单按平台补齐。

---

## 6. 组件与动效预算

- **允许**：胶囊导航选中、Tab 圆角选中边、主机卡 hover 描边、状态点。  
- **禁止**：无首大动效、卡片翻转、无意义粒子/辉光。  
- 主机用圆角抬升卡；列表不再用 Forge 发丝侧栏行。

---

## 7. 落地顺序

1. ✅ Termius 主题 JSON + 顶栏 / Vault / 全宽终端壳  
2. 桌面 SSH 从 Vault 一键连接  
3. 命令面板（Cmd+K）  
4. 设置页（语言、字体、主题切换含 Forge 备选）  
5. 双栏文件 / 远程桌面接入同一 Body
